# Distributed Blood Bank Coordination System with AI-Based Demand Forecasting

**Advanced DBMS Semester Project**

## Overview

### Introduction

In Pakistan, many blood banks work independently, causing **blood shortages** in some facilities and **wastage** in others. This project proposes a **distributed database system** that enables real-time inventory sharing between blood banks.

An **AI-based demand forecasting model** will predict future blood needs and help reduce shortages and wastage. The project uses **distributed DB, data fragmentation, NoSQL, and basic machine learning** concepts.

## Tech Stack

- Oracle 21c Express Edition (Distributed Database)
- MongoDB (NoSQL Layer)
- Python (AI Forecasting Model)
- Power BI (Dashboard)
